# Programming Bootcamp Quiz

A single-player, console-based JavaScript quiz covering **Loops, Conditionals, Variables, and JavaScript Basics**.

## Features

- Four multiple-choice questions per selected category
- Four difficulty levels: Hard (20 points), Medium (15), Easy (10), and Very Easy (5)
- Immediate correct/incorrect feedback and a running score
- Completed categories cannot be repeated
- Continue or quit after each category; a final report shows the player, score, and completed categories

## Run

Requires [Node.js](https://nodejs.org/).

```bash
npm install readline-sync
node main.js
```
