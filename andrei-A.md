# Design Document

## Andrei A

| Feature                            | Planned use                                                                                                                                                                                                                                                                                                                                                                            |
| ---------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Variables                          | let playerName — stores the player's name entered at the start.<br>let playAgain — boolean flag for the while-loop controlling whether to continue after a category.<br>const prompt — imports the readline-sync package for console input.                                                                                                                                            |
| Conditionals (if, if-else, switch) | if statement for input validation — checks the entered answer is one of A, B, C, or D before proceeding.<br>Logical operators (&&, \|\|) used to validate answer choice, e.g. if (choice === "A" \|\| choice === "B" \|\| ...).                                                                                                                                                        |
| Loops (for, while, do-while)       | do-while loop for input validation — forces the player to re-enter their answer if it is not A, B, C, or D; guaranteed to run at least once.<br>while loop for the main game loop — after completing a category, the player is asked if they want to continue.<br>Nested for loop when displaying final results — iterates through the results array to show a per-category breakdown. |
| 1D- and 2D-arrays                  | 1D array stores the number of correct answers per category for the final results breakdown.<br>1D array tracks which questions have already been answered, preventing repeats.<br>1D array  within each Question object stores the four multiple-choice options as strings.                                                                                                            |
| Objects                            | Player object: { name, score, categoriesCompleted } — stores the player's name, running score, and an array of completed category indices.<br>Player object properties accessed and modified.<br>                                                                                                                                                                                      |
| Functions                          | getPlayerAnswer() — uses a do-while loop to prompt for and validate the player's answer; returns a validated A/B/C/D string.<br>showResults() — displays the final score, pass/fail message, and per-category breakdown.<br>                                                                                                                                                           |
